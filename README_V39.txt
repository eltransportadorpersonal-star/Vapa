VAPA V39 - Catálogo sin duplicados

Se eliminó la tarjeta estática de Casa Mila del catálogo público y se deshabilitó su ficha antigua de demostración. Los registros de Supabase NO se alteran. El catálogo muestra únicamente propiedades con estado published que devuelve Supabase. Si Casa Mila figura pending_review, debe aprobarse desde /admin/ para aparecer.

Para publicar: descomprime y sube el CONTENIDO de esta carpeta al proyecto vapa1 en Netlify. No es necesario ejecutar SQL. Después recarga la página con Ctrl+F5.

Nota: las fichas dinámicas de Supabase aún muestran un aviso al pulsar Ver propiedad; la página de detalle/reserva dinámica queda para una actualización posterior.
